Connecting a rack

ESP32 + NAU7802/HX711 firmware contract

Each rack has its own device key. The controller posts a stabilised weight every 500 ms; RackSense answers with buzz: true when the alert fires, then the firmware pulls the queued commands on its next poll.

Download ESP32 sketch API reference 
# one reading from the rack (grams, optional per-corner cells)
curl -X POST https://<your-rack-host>/api/device/telemetry \
  -H "X-Device-Key: <rack key>" -H "Content-Type: application/json" \
  -d '{"weight_g": 17320, "cells_g": [4820, 4310, 4190, 4000]}'
# queued buzzer / tare commands for this rack
curl https://<your-rack-host>/api/device/<rack key>/commands
# config the firmware needs: armed, capacity, avg item weight, settle window
curl https://<your-rack-host>/api/device/<rack key>/config
